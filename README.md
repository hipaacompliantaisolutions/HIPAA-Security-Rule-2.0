Understanding the Shift From Addressable to Mandatory HIPAA Controls</span></strong></h3><p dir="ltr"><span style="font-family: 'book antiqua', palatino, serif;">Under the existing HIPAA Security Rule, implementation specifications are categorized as either required or addressable.</span></p><p dir="ltr"><span style="font-family: 'book antiqua', palatino, serif;">Required specifications must be implemented.
